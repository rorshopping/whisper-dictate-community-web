Privacy notice

Last updated: September 24, 2026

Short version: this landing page has no accounts, forms, cookies, analytics, or tracking. The app’s documented dictation path is local after the selected speech model has been acquired.

This website

community-site/ is a static HTML/CSS/JavaScript site. It has no server-side application, user database, advertising script, analytics script, external font, or payment form. The browser loads its own JavaScript and the same-origin releases.json manifest only. Loading an external link, such as GitHub or a model license, is a separate visit to that destination.

Audio and local app data

  • Audio is recorded only while the user invokes dictation and is processed by the app on the user’s computer.
  • The documented model-based transcription path does not upload recorded audio to a speech service.
  • Application logs, transcription history, configuration, and personal correction or snippet files remain on the user’s machine and can be deleted by the user.
  • The site itself cannot see or inspect microphone input, local app files, or dictation results.

First model download

The model weights are not bundled with the app or this site. On first use of a language, the documented app downloads the selected model from Hugging Face. That request necessarily contacts Hugging Face and may expose the requester’s IP address, network metadata, and user-agent to that service. The model publisher’s terms and privacy practices apply to that download.

After the model is present in the local cache, the documented local transcription path can run offline. “Offline” does not mean the first model acquisition is offline.

Download requests

When a community artifact is eventually published, a download request will be made directly to the canonical URL listed in releases.json. The site does not proxy files through an application server and does not store a user identifier in the manifest.

Questions and changes

For a question about the software or this notice, use the public repository and its current issue/contact channels: source repository. This notice describes this static page and the documented local workflow; it does not replace the source repository’s license, model license, or third-party notices.
