Open source setup

First run

Acquire once, then work offline

“Offline” applies after model acquisition. The community build does not bundle the model weights, so the first use of each language needs a network connection.

  1. 1

    Choose a verified artifact

    Use a link from the release manifest, then compare its SHA-256 checksum with the manifest before launching it.

  2. 2

    Start the app once online

    On first use of a language, the app fetches the documented NVIDIA model from Hugging Face. Each checkpoint is currently described as approximately 2.4 GB.

  3. 3

    Review the model terms

    The model publisher’s license applies to the weights. They are downloaded directly by the app and are not redistributed with this site or the app archive.

  4. 4

    Use local transcription

    Once the model is cached, recording and transcription stay local. Later dictation does not need to send audio to a speech service.

System requirements

Requirements can differ by source revision and artifact. Treat the manifest and release notes as the source of truth for a published build.

Windows x64

  • Windows 10 or 11, 64-bit
  • Microphone and keyboard access
  • NVIDIA GPU recommended for acceleration
  • CPU fallback is documented, but may be slower

macOS Apple Silicon

  • macOS 13 or newer, arm64
  • Microphone permission for the launcher
  • Accessibility / Input Monitoring for dictation and paste
  • Apple GPU acceleration where supported; CPU fallback is documented

Storage and source builds

  • Allow roughly 2.4 GB per downloaded language model
  • Leave additional space for the app, cache, and logs
  • Packaged artifacts do not require Python
  • Source setup documents Python 3.12+

Verify before you run

Checksums confirm that a downloaded file matches the manifest. They do not replace reviewing the release notes or source.

SHA-256 checksums will appear here when a canonical release is published.

PowerShell

Get-FileHash .\WhisperDictate-….zip -Algorithm SHA256

macOS / Linux

shasum -a 256 WhisperDictate-….zip

If a checksum differs, do not run the file. Re-download it and compare the exact filename and hash from releases.json.

Troubleshooting

Start with the release manifest and the source README. The answers below describe the documented community workflow, not a support SLA.

Why are the download buttons disabled?

No canonical community release has been entered into releases.json yet. The site intentionally refuses to invent a download URL. Watch the source repository’s release page and update the manifest only after artifacts and checksums are verified.

Why does the first run need internet?

Speech model weights are not bundled. The first use of each language downloads the selected model from Hugging Face. After the model is cached, the documented transcription path runs locally and can work offline.

What permissions does macOS need?

Grant Microphone access to the app or launcher. Dictation and text insertion also use Accessibility / Input Monitoring, and the documented launcher may request Automation access for System Events. Denied permissions can allow recording without allowing text to be inserted.

What if transcription is slow or the GPU is not used?

Check the release/source configuration and the app log. GPU acceleration depends on the platform, available hardware, model, and chosen device. The documented configuration can fall back to CPU, which is generally slower.

What should I do if a checksum does not match?

Do not run the artifact. Confirm the exact filename, download it again from the canonical URL in the manifest, and compare the full SHA-256 digest. A mismatch is a reason to stop and investigate.

Can I redistribute a ZIP or the models?

Do not assume that the model or software terms permit redistribution. Read the repository software license, the linked model licenses, and the repository’s third-party notices first.
